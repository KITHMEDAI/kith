## What this is

A potential shared-upside development + commercialisation partnership to build a
documentation product for an Australian healthcare / NDIS workflow, starting with
one organisation, one workflow, one tightly scoped pilot.

- **Steve brings:** Australian market knowledge, commercial strategy, product
  positioning, partner development, structured route to market.
- **Kith brings:** technical capability, delivery commitment, security foundations.

## Our stance (agreed 2026-10-18)

- Kith has zero revenue so far — this is a real chance to move into the market, so
  we're willing to compromise on ownership splits and cut some slack.
- The non-negotiable: **don't get scammed** — no building and delivering without a
  clear, enforceable path to getting paid / sharing upside.
- No paid retainer to AGI360 — shared upside only.
- Keep the core Kith engine ours; AU-specific work can be shared or licensed.
- Any exclusivity for Australia must be earned through milestones, not open-ended.
